# RoboFleet

Symulator floty robotów magazynowych: aplikacja webowa do projektowania wirtualnego magazynu na siatce 20 × 20, zarządzania flotą 3–10 symulowanych robotów, tworzenia zleceń transportowych z automatycznym przydziałem i planowaniem tras bez kolizji, podglądu symulacji na żywo oraz statystyk przebiegów.

Projekt semestralny z przedmiotu **Inżynieria Oprogramowania**, Wydział Matematyki i Nauk Informacyjnych, Politechnika Warszawska.
